# 📱 Multi-Activity Android App

A beginner-friendly Android application built using **Kotlin/Java** and **Android Studio** that demonstrates the implementation of **multiple activities**, **intent-based navigation**, and **basic mathematical operations**.

This project contains three useful mini modules:

* 🧮 Calculator
* 🔢 Even / Odd Number Checker
* 🔁 Factorial Calculator

The app is designed to help students and beginners understand the fundamentals of Android app development with practical examples.

---

# 🚀 Features

## 🧮 Calculator Module

Perform basic arithmetic operations:

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division

### Features

* Simple and clean user interface
* Instant calculation results
* User-friendly input fields

---

## 🔢 Even / Odd Number Checker

Enter any number and instantly check whether it is:

* ✅ Even
* ✅ Odd

### Features

* Fast result generation
* Beginner-level logic implementation
* Easy-to-use design

---

## 🔁 Factorial Calculator

Calculate the factorial of a given number instantly.

### Example

5! = 120

### Features

* Handles user input dynamically
* Displays factorial result immediately
* Demonstrates loop and mathematical logic
